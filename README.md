# FizLabKZ — физика зертханасы

Смартфон датчиктерімен физикалық өлшеулер жүргізуге арналған қазақ тіліндегі веб-қосымша (PWA).
Айфонда (Safari) және андроидта ашылады, басты экранға орнатылады, бір рет ашылған соң интернетсіз жұмыс істейді.

Сілтеме: https://fizlabkz.github.io/

`index.html` файлы App Inventor-дегі FizLabKZ Android қосымшасының `fizlab.html` файлымен бірдей.
